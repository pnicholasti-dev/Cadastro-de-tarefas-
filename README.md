# 📋 Sistema de Cadastro de Tarefas

Projeto desenvolvido em **Java** com o objetivo de praticar conceitos fundamentais de **Programação Orientada a Objetos (POO)**, estruturas de dados, validações e interação com o usuário por meio do terminal.

## 🚀 Funcionalidades

O sistema permite ao usuário:

* ➕ Inserir novas tarefas
* 📋 Listar tarefas cadastradas
* ✏️ Alterar tarefas existentes
* 🗑️ Excluir tarefas
* 🔎 Impedir o cadastro de tarefas duplicadas
* ⚠️ Validar informações inseridas pelo usuário
* 🚪 Encerrar o programa através do menu

## 🧠 Conceitos utilizados

Durante o desenvolvimento foram aplicados:

* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Construtores
* `ArrayList`
* Estruturas condicionais (`if/else`)
* Estruturas de repetição (`for`, `do/while`)
* `switch/case`
* Entrada de dados com `Scanner`
* Validação de informações
* Operações de CRUD

## 📁 Estrutura

```text
src/
├── Main.java
└── Tarefa.java
```

### `Tarefa.java`

Responsável por representar uma tarefa do sistema, contendo seus atributos e métodos de acesso e alteração.

### `Main.java`

Responsável pela execução da aplicação, menu principal, interação com o usuário e gerenciamento da lista de tarefas.

## 🎯 Objetivo

O projeto foi desenvolvido como prática dos fundamentos de Java, buscando melhorar minha compreensão sobre **POO, manipulação de listas, lógica de programação e desenvolvimento de aplicações interativas**.
